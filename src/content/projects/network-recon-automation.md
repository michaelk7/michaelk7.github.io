## Problem

Running and re-running Nmap scans by hand across lab networks was slow and inconsistent between testers.

## What I built

A set of Python and Bash scripts that:

- Run a consistent set of Nmap scans against defined lab ranges.
- Save results in a structured format so runs can be compared.
- Cut out the repetitive setup work at the start of each test.

## Result

Reduced manual testing time by roughly **40%**.
